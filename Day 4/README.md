# Day 4 — Сравнение temperature в промптах

Node.js CLI, который решает логическую задачу про 25 лошадей при **трёх настройках temperature** (0, 0.7, 1.2) через [Cursor SDK](https://cursor.com/docs/sdk/typescript) и сравнивает точность, креативность и разнообразие ответов.

> **Важно:** Cursor SDK (`AgentOptions`) не принимает параметр `temperature` напрямую. Поэтому значения 0 / 0.7 / 1.2 задаются **инструкцией в промпте** — модель получает явное указание, как вести себя при «низкой», «средней» или «высокой» температуре.

## Задача

**Условие:** есть 25 лошадей. В каждом забеге могут участвовать до 5 лошадей. Нужно найти минимальное число забегов, чтобы определить **1, 2 и 3 место** среди всех лошадей.

**Эталонный ответ:** 8 забегов.

**Цель Day 4:** проверить, как «температура» (через текстовые инструкции) влияет на:

- точность числового ответа;
- креативность формулировок (аналогии, альтернативы, длина текста);
- разнообразие ответов между прогонами.

Скрипт также сохраняет режимы промптинга из Day 3 (`direct`, `step`, `meta`, `experts`), но фокус этого дня — **temperature**.

## Требования

- Node.js 18+
- API-ключ Cursor ([Dashboard → Integrations](https://cursor.com/dashboard/integrations))
- Установленный Cursor CLI (для `CURSOR_RUNTIME=local`)

## Развёртывание

```bash
cd "Day 4"
npm install
cp .env.example .env
```

Открой `.env` и укажи свой ключ:

```env
CURSOR_API_KEY=cursor_your-key-here
CURSOR_MODEL=composer-2.5
CURSOR_RUNTIME=local
```

| Переменная | Описание |
|---|---|
| `CURSOR_API_KEY` | API-ключ Cursor |
| `CURSOR_MODEL` | Модель (по умолчанию `composer-2.5`) |
| `CURSOR_RUNTIME` | `local` — агент на вашей машине; `cloud` — облачный агент (нужен Storage mode в Cursor) |

## Команды

### Temperature (основной сценарий Day 4)

```bash
# Прогон всех трёх temperature за один запуск
npm start -- --mode temperature

# Сравнение сохранённых результатов без повторных API-вызовов
npm start -- --compare-temp
```

Результаты сохраняются в:

- `results/temp-0.json`
- `results/temp-0.7.json`
- `results/temp-1.2.json`

### Режимы промптинга (из Day 3, опционально)

```bash
npm start -- --mode direct
npm start -- --mode step
npm start -- --mode meta
npm start -- --mode experts
npm start -- --compare
```

Свою формулировку задачи можно передать после флагов:

```bash
npm start -- --mode temperature "Есть 25 лошадей..."
```

## Температурные режимы

### `temperature = 0` — детерминированный ответ

**Инструкция в промпте:** один канонический ход рассуждения, без альтернатив, без украшений, сухие и однозначные формулировки.

**Суть:** имитация «холодной» генерации. Модель должна дать один строгий путь к ответу — как при `temperature=0` в классических LLM API. Подходит для фактов, классификации, извлечения данных, математики и JSON.

### `temperature = 0.7` — умеренная вариативность

**Инструкция в промпте:** допустима вариативность формулировок и пояснений, но факты сохраняются; можно добавить краткую аналогию.

**Суть:** баланс между точностью и читаемостью. Ответ может быть чуть живее, с пояснениями «для человека». Подходит для объяснений, чата и учебных ответов.

### `temperature = 1.2` — высокая креативность

**Инструкция в промпте:** разнообразный стиль, метафоры, несколько гипотез, альтернативные схемы — даже спорные.

**Суть:** имитация «горячей» генерации. Модель может предлагать нестандартные идеи и длинные тексты, но растёт риск ошибок и галлюцинаций. Подходит для мозгового штурма, нейминга и черновиков.

## Результат сравнения

Прогон на задаче про 25 лошадей (модель `composer-2.5`, `CURSOR_RUNTIME=local`):

```
===== СРАВНЕНИЕ TEMPERATURE =====
числа: temp-0=7 | temp-0.7=7 | temp-1.2=6
эталон: 8
точность: temp-0 ошибка (7), temp-0.7 ошибка (7), temp-1.2 ошибка (6)
креативность: temp-0 низкая (378 слов) | temp-0.7 средняя (382 слов, аналогия) | temp-1.2 высокая (794 слов, аналогия, альтернативы)
разнообразие: тексты отличаются; числа разошлись; разброс длины 416 слов
Ни одна настройка не попала в эталон 8. temperature=0 лучше для фактов, классификации, извлечения, математики и JSON. temperature=0.7 лучше для объяснений, чата и учебных ответов. temperature=1.2 лучше для мозгового штурма, нейминга и черновиков — ценой риска галлюцинаций.
```

**Выводы:**

| Temperature | Ответ | Точность | Креативность | Комментарий |
|---|---|---|---|---|
| 0 | 7 | ошибка | низкая (378 слов) | Самый сухой текст, но всё равно не попал в эталон |
| 0.7 | 7 | ошибка | средняя (382 слов, аналогия) | Чуть живее, добавила аналогию |
| 1.2 | 6 | ошибка | высокая (794 слов, аналогия, альтернативы) | Самый длинный и креативный ответ, но и самый далёкий от эталона |

Ни одна «температура» не дала правильный ответ 8 — на этой логической задаче инструкции в промпте не заменяют настоящий sampling-параметр, но хорошо показывают trade-off: **ниже temperature → короче и суше**, **выше → длиннее и креативнее, но менее точно**.
