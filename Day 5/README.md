# Day 5 — Сравнение слабой, средней и сильной модели

Node.js CLI, который решает логическую задачу про 25 лошадей **тремя моделями разного уровня** через [Cursor SDK](https://cursor.com/docs/sdk/typescript) и сравнивает качество ответа, скорость, токены и стоимость.

## Задача

**Условие:** есть 25 лошадей. В каждом забеге могут участвовать до 5 лошадей. Нужно найти минимальное число забегов, чтобы определить **1, 2 и 3 место** среди всех лошадей.

**Эталонный ответ:** 8 забегов.

**Цель Day 5:** на **одном и том же запросе** сравнить три модели:

| Уровень | Модель | Роль |
|---|---|---|
| Слабая | `gpt-5.4-nano` | Быстрая и дешёвая, для простых задач |
| Средняя | `composer-2.5` | Баланс скорости и качества, модель Cursor |
| Сильная | `claude-opus-5` | Максимальное качество рассуждений |

Скрипт для каждой модели:

1. Отправляет одинаковый промпт через Cursor SDK.
2. Извлекает число забегов из ответа.
3. Проверяет, есть ли в тексте схема определения top-3.
4. Замеряет время, токены и оценивает стоимость.

> Скрипт также сохраняет режимы из Day 3 (промптинг) и Day 4 (temperature), но фокус этого дня — **сравнение моделей**.

## Требования

- Node.js 18+
- API-ключ Cursor ([Dashboard → Integrations](https://cursor.com/dashboard/integrations))
- Установленный Cursor CLI (для `CURSOR_RUNTIME=local`)
- Доступ к выбранным моделям в вашем аккаунте Cursor

## Развёртывание

```bash
cd "Day 5"
npm install
cp .env.example .env
```

Открой `.env` и укажи свой ключ:

```env
CURSOR_API_KEY=cursor_your-key-here
CURSOR_MODEL=composer-2.5
CURSOR_RUNTIME=local
CURSOR_MODEL_WEAK=gpt-5.4-nano
CURSOR_MODEL_MEDIUM=composer-2.5
CURSOR_MODEL_STRONG=claude-opus-5
```

| Переменная | Описание |
|---|---|
| `CURSOR_API_KEY` | API-ключ Cursor |
| `CURSOR_MODEL` | Модель по умолчанию для остальных режимов |
| `CURSOR_RUNTIME` | `local` или `cloud` |
| `CURSOR_MODEL_WEAK` | Слабая модель (по умолчанию `gpt-5.4-nano`) |
| `CURSOR_MODEL_MEDIUM` | Средняя модель (по умолчанию `composer-2.5`) |
| `CURSOR_MODEL_STRONG` | Сильная модель (по умолчанию `claude-opus-5`) |

Если модель недоступна в каталоге аккаунта, скрипт пробует запасные варианты из списка по умолчанию.

## Команды

### Модели (основной сценарий Day 5)


Результаты сохраняются в:

## Модели

### Слабая — `gpt-5.4-nano`

Компактная и экономичная модель. Минимальная стоимость за токен, подходит для простых запросов, классификации и черновиков. На сложных логических задачах может уступать более крупным моделям.

**Запасные:** `gpt-5-mini`, `gemini-2.5-flash`

### Средняя — `composer-2.5`

Модель Cursor по умолчанию. Баланс между скоростью, стоимостью и качеством рассуждений. Оптимальный выбор для повседневной разработки и большинства задач в IDE.

### Сильная — `claude-opus-5`

Топовая модель для сложных рассуждений, архитектурных решений и многошаговых задач. Самая дорогая, но с наибольшим потенциалом точности на нетривиальных задачах.

**Запасные:** `gpt-5.5`, `grok-4.6`

## Результат сравнения

Прогон на задаче про 25 лошадей (`CURSOR_RUNTIME=local`):

```
===== СРАВНЕНИЕ МОДЕЛЕЙ =====
числа: слабая=7 (gpt-5.4-nano) | средняя=7 (composer-2.5) | сильная=7 (claude-opus-5)
эталон: 8
качество: слабая: ошибка (7), схема top-3 есть | средняя: ошибка (7), схема top-3 есть | сильная: ошибка (7), схема top-3 есть
скорость: слабая=36.5 с | средняя=14.0 с | сильная=60.3 с
токены: слабая=9548 | средняя=6152 | сильная=9387
стоимость: слабая=$0.008627 (оценка) | средняя=$0.007616 (оценка) | сильная=$0.125592 (оценка)
Ни одна модель не попала в эталон 8. Быстрее всех средняя (14.0 с). Дешевле всех средняя ($0.007616 (оценка)).
```

**Выводы:**

| Модель | Ответ | Скорость | Токены | Стоимость | Комментарий |
|---|---|---|---|---|---|
| Слабая (`gpt-5.4-nano`) | 7 | 36.5 с | 9548 | $0.0086 | Схема top-3 есть, но ответ неверный |
| Средняя (`composer-2.5`) | 7 | **14.0 с** | **6152** | **$0.0076** | Самая быстрая и дешёвая, лучший баланс |
| Сильная (`claude-opus-5`) | 7 | 60.3 с | 9387 | $0.1256 | Самая дорогая и медленная, точность не выше |

На этой задаче **ни одна модель не дала эталон 8**, хотя все три описали схему определения top-3. Сильная модель не оправдала цену: ответ тот же (7), но в ~4 раза дороже и в ~4 раза медленнее средней. **Composer 2.5** оказался оптимальным по скорости и стоимости.

## Примечания
